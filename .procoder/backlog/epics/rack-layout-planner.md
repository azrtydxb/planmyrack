## Description

PlanMyRack: plan a 19" or 10" server rack before buying or drilling, on phone, tablet and in
the browser from one Expo codebase. One epic because the pieces are worthless apart — a rack
canvas with no storage plans nothing twice, and storage with no cabling records half the truth.

Delivers: multi-rack layouts with front and rear faces; half-U drag placement that never
overlaps; devices with names, colours, sizes and port counts; cable management, PDUs, shelves
and blanks; port-to-port network cabling and PDU outlet mapping with one cable per port; two
exclusive storage modes (local SQLite, or a locally installed server several devices share);
JSON/PNG/PDF/CSV export; an equipment catalogue and saved templates; undo/redo; and
store-shippable iOS, Android and web builds.

Seeded from .procoder/specs/rack-layout-planner.md — one story per acceptance criterion, each
naming the plan task that implements it and the test that proves it.
